# Estudos de C# e .NET

Este repositório foi criado para registrar e organizar meus estudos de **C# e .NET**.

O conteúdo acompanha principalmente o curso **C# COMPLETO — Programação Orientada a Objetos + Projetos**, do professor **Nelio Alves**, além de exercícios, testes e anotações complementares que eu desenvolver durante meu aprendizado.

## 🎯 Objetivo

Meu objetivo com este repositório é construir uma base sólida em **C#**, **.NET** e principalmente em **Programação Orientada a Objetos**, praticando os conceitos estudados por meio de exercícios e pequenos projetos.

Além de servir como material de consulta, este repositório também será utilizado para acompanhar minha evolução com a tecnologia.

## ▶️ Executando os projetos

Verificar a versão instalada do .NET:

```bash
dotnet --version
```

Criar um novo projeto console:

```bash
dotnet new console
```

Restaurar dependências:

```bash
dotnet restore
```

Compilar:

```bash
dotnet build
```

Executar:

```bash
dotnet run
```
